# TimePill · 像素时光胶囊

一个卡通像素风的私人时光胶囊网页，用来保存写给过去或未来自己的信。

## 功能

- 新建、编辑、删除时光胶囊
- 搜索标题或信件内容
- 数据保存在浏览器 `localStorage`
- 纯 HTML / CSS / JavaScript，无需后端
- 可直接部署到 GitHub Pages

## GitHub Pages 部署

1. 在 GitHub 新建仓库，例如 `timepill`。
2. 上传 `index.html`、`README.md`、`favicon.ico`。
3. 打开 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/ (root)`，保存。
6. 等待部署完成。

## 隐私说明

网页中创建的信件保存在当前浏览器的本地存储中，不会因为部署到 GitHub Pages 而上传到 GitHub。

请注意：清除浏览器网站数据可能同时清除已保存的胶囊。
